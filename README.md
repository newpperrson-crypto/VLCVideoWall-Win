# VLCVideoWall — видеостена для Windows

Приложение превращает один ПК на Windows в видеостену из IP-камер на базе
[VLC](https://www.videolan.org/) и следит за тем, чтобы картинка не пропадала.

Мозаику рисует встроенный компоновщик VLC, но он **никогда не переподключает
RTSP-поток**: если камера пропала, плитка остаётся чёрной до перезапуска всей
стены. Это приложение добавляет сторож, который замечает мёртвый канал, проверяет
саму камеру, переподключает **только** сломанную плитку и поднимает VLC, если тот
упал.

```
┌──────────────────────┐      HTTP 127.0.0.1:4212      ┌────────────────────┐
│  VLCVideoWall.exe       │ ────────────────────────────► │  vlc.exe           │
│  (WinForms, трей)    │   /requests/vlm.xml           │  -I dummy          │
│                      │   /requests/vlm_cmd.xml       │  mosaic + display  │
└──────────┬───────────┘                               └────────────────────┘
           │ запускает / останавливает / сторожит            ▲
           ▼                                                 │
┌──────────────────────┐   пишет Mosaic.active.vlm            │
│  watchdog.ps1        │ ────────────────────────────────────┘
│  (PowerShell 5.1)    │   RTSP OPTIONS → stop/play одного канала
└──────────────────────┘
```

## Возможности

| | |
|---|---|
| **Самовосстановление** | Пропажа канала замечается за ~10 с и лечится на месте. Живые плитки не трогаются. |
| **Проверка камеры перед повтором** | Источник опрашивается запросом RTSP `OPTIONS`. Нет сети — ждём. Ответ `401` — пауза до 2 минут, чтобы камера не заблокировала IP за подбор пароля. |
| **Присмотр за VLC** | Если процесс VLC упал или его HTTP-интерфейс перестал отвечать, плеер перезапускается. |
| **Сетки до 16 окон** | Пресеты `1x1 … 4x4` или произвольное число колонок и строк, но не больше 16 окон. |
| **Разрешение полотна** | HD 1280×720, Full HD 1920×1080, 2K 2560×1440, 4K 3840×2160, SXGA 1280×1024 или своё. Чёрные полотна создаются автоматически. |
| **Значок в трее** | Запуск, остановка и выход из меню значка; сворачивание в трей и автозапуск при входе в Windows. |
| **Окно поверх стены** | Параметр «Окно поверх всех окон» на вкладке «Общие» (включён по умолчанию): настройки видно поверх видео. |
| **Повторный запуск** | Запуск `VLCVideoWall.exe`, когда приложение уже работает, разворачивает его окно вместо предупреждения. |
| **Ротация журнала** | Свой журнал с настраиваемым сроком хранения (по умолчанию 30 дней). |
| **Без установки рантаймов** | Публикуется одним самодостаточным `.exe`. Сторож — встроенный Windows PowerShell 5.1. |
| **Переносимая папка** | В реестр пишется только ключ автозапуска (и то по желанию). Папку можно скопировать в любое место. |
- Стена в окне: размер окна равен разрешению полотна (`windowed`, по умолчанию выключено)
- Звук выбранной камеры с переключением по клику на плитке и значком на стене

## Требования

- Целевая машина: Windows 10 x64 или новее
- [VLC 3.0.x, **64-бит**](https://www.videolan.org/vlc/download-windows.html)
- Сеть до камер (RTSP)
- Для сборки: .NET SDK 10 (проект на `net10.0`)

## Быстрый старт

1. Установите VLC (64-бит). Приложение найдёт его в реестре или в `Program Files`,
   либо укажите путь к `vlc.exe` на вкладке **Общие**.
2. Распакуйте архив релиза в отдельную папку, например `C:\VideoWall`, и запустите
   оттуда `VLCVideoWall.exe`. Не запускайте прямо из «Загрузок»: `Mosaic.conf`,
   журнал и полотна создаются рядом с программой.
   В архиве: `VLCVideoWall.exe`, `watchdog.ps1` (обязателен), `Mosaic.conf.example`,
   `README.txt`, `LICENSE`.
3. На вкладке **Камеры и сетка** добавьте адреса RTSP, выберите сетку и полотно.
4. Нажмите **Сохранить и перезапустить** — стена уйдёт в полноэкранный режим,
   а окно настроек спрячется в трей.

Первая вкладка **Стена** показывает текущую раскладку: закрашенные ячейки — камеры,
пунктирные — свободные места; номера окон идут слева-направо, сверху-вниз.
Последняя вкладка **О программе** — название, описание, версия и год.

Настройки лежат в файле `Mosaic.conf` рядом с программой:

```ini
layout = 2x2
canvas = 1920x1080

cam ch1 rtsp://user:password@192.0.2.11:554/Streaming/Channels/101
cam ch2 rtsp://user:password@192.0.2.12:554/live/ch00_1

logkeep = 30
```

Порядок строк — это порядок окон: **слева-направо, сверху-вниз**. Остальные ключи
описаны в [docs/configuration.md](docs/configuration.md), там же про кодирование
паролей и файлы полотен.

> В `Mosaic.conf` хранятся пароли камер. В репозиторий этот файл не попадает
> (он в `.gitignore`); шаблон — [`config/Mosaic.conf.example`](config/Mosaic.conf.example).

## Как работает восстановление

1. Раз в ~5 с сторож читает `/requests/vlm.xml` и сверяет состояние каждого канала.
2. Канал, который перестал быть `playing`, помечается мёртвым после двух опросов
   подряд — один сбой часто оказывается случайным.
3. Перед перезапуском проверяется источник запросом RTSP `OPTIONS` (таймаут 2,5 с,
   логин и пароль берутся из URL):
   * нет TCP-соединения → камера недоступна: VLC не трогаем, ждём;
   * `401` → неверный логин или пароль: пишем в журнал, повтор не чаще 2 минут;
   * TCP открыт, ответа RTSP нет → камера заблокировала клиента: повтор через ~60 с;
   * любой ответ RTSP → камера жива: переподключаем.
4. Переподключение — `stop`, затем `play` только для этого канала, с паузой
   5 → 10 → 15 с. Один `play` не работает, если у канала включён `loop`.
5. Если процесс VLC завершился или его HTTP-интерфейс молчит, плеер запускается
   заново вместе со всей стеной.

Проверить восстановление по-настоящему можно только обрывом связи: отключите
камеру (или кабель) на полминуты и посмотрите журнал — там должны появиться строки
о падении и восстановлении канала.

## Сборка

```powershell
dotnet publish src/VLCVideoWall/VLCVideoWall.csproj -c Release -o dist
```

`dist\VLCVideoWall.exe` — один самодостаточный файл (~63 МБ); на целевой машине не
нужны ни .NET, ни VC++. Положите его рядом с `watchdog.ps1`; `Mosaic.conf` и
полотна создадутся при первом запуске.

Только сборка, без публикации:

```powershell
dotnet build src/VLCVideoWall/VLCVideoWall.csproj -c Release
```

## Ограничения

* Каждая плитка — отдельная RTSP-сессия. 16 окон означают 16 сессий; недорогие
  камеры могут отказать уже после 2–4.
* Мозаику рисует VLC, поэтому набор кодеков — его; дополнительного
  транскодирования нет.
* Управляющее приложение рассчитано на одну стену на машине (один процесс).
* Если камера перестала присылать кадры, но сессия RTSP осталась открытой, VLC
  продолжает считать канал живым, и автоматического перезапуска не будет —
  на плитке останется последний кадр. Подробнее в
  [docs/troubleshooting.md](docs/troubleshooting.md).
